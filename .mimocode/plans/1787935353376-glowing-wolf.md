# 固件更新调试结论

## 问题根因
用户只烧录了 app hex，没有烧录 combined.hex。Bootloader 不在 Flash 中。

## Application 执行流程验证 ✓
- C:10 → 收到 ENTER_IAP ✓
- IAP → 进入处理 ✓
- ACK → 发送响应 ✓
- E → 擦除标志页 ✓
- W → 写入标志 ✓
- R → 复位到 ISP ✓
- 但复位后 MCU 启动了 Application（因为 Bootloader 不存在）

## 解决方案
必须烧录 `combined.hex`（包含 Bootloader + Application），不能只烧录 app hex。

## 烧录步骤
1. STC-ISP 选择 `D:\STC\project\USB_HUB_Meter\Merged_Firmware\combined.hex`
2. 烧录到 MCU
3. 上位机测试固件更新
