# 配置文件设计方案

## 1. 设计原则

- 上电时读取 `config.json`，不存在则自动生成默认值
- 配置文件与 exe 同目录
- 只放**用户可调**的参数，协议常量/固件常量不放入

## 2. 分类原则

| 类别 | 是否可配置 | 原因 |
|------|-----------|------|
| 串口参数 (波特率等) | 是 | 不同设备可能不同 |
| INA226 换算参数 (currentLSB, Rshunt) | 是 | 硬件改了采样电阻就需要改 |
| 图表设置 (刷新间隔、最大点数) | 是 | 用户偏好 |
| 调试日志 (启用、最大行数) | 是 | 用户偏好 |
| 窗口状态 (大小、位置) | 是 | 记住上次状态 |
| 协议帧头/命令ID | 否 | 必须与 MCU 固件一致 |
| Bootloader 常量 (页大小/块大小) | 否 | 硬件决定，改了会变砖 |

## 4. 涉及文件

| 文件 | 修改内容 |
|------|----------|
| `AppConfig.cs` | **新建** — 配置模型类 + 加载/保存/默认值 |
| `Ina226Data.cs` | 换算参数从硬编码改为接收配置值 |
| `Form1.cs` | 初始化时加载配置，应用到串口/图表/调试 |
| `FirmwareUpdater.cs` | 页大小等常量不变（硬件决定） |

## 5. AppConfig.cs 设计

```csharp
class AppConfig
{
    // 子配置对象
    SerialConfig Serial { get; set; }
    Ina226Config Ina226 { get; set; }
    ChartConfig Chart { get; set; }
    DebugConfig Debug { get; set; }
    WindowConfig Window { get; set; }

    // 静态方法
    static AppConfig Load(string path);   // 加载，失败返回默认
    static AppConfig CreateDefault();     // 默认值
    void Save(string path);               // 保存
}

class SerialConfig
{
    int BaudRate = 115200;
    int DataBits = 8;
    string Parity = "None";     // None/Odd/Even
    string StopBits = "One";    // One/Two
    int ReadTimeout = 1000;
    int WriteTimeout = 1000;
}

class Ina226Config
{
    double CurrentLSB = 0.0001;     // A/bit
    double RShunt = 0.01;           // Ω
    double VoltageLSB = 1.25;       // mV/bit
    double ShuntVoltageLSB = 2.5;   // µV/bit
    double PowerMultiplier = 25.0;  // powerLSB = multiplier × currentLSB
}

class ChartConfig
{
    int AutoRefreshInterval = 500;
    int MaxPoints = 200;
    int[] IntervalOptions = [200, 500, 1000, 2000];
    int[] MaxPointsOptions = [100, 200, 500, 1000];
}

class DebugConfig
{
    bool LogEnabled = true;
    int MaxLines = 500;
}

class WindowConfig
{
    int Width = 900;
    int Height = 620;
    int X = -1;    // -1 = 居中
    int Y = -1;
}
```

## 6. Ina226Data 改造

当前换算直接写死在属性里，改为接收配置：

```csharp
struct Ina226Data
{
    // ... 原始值字段不变 ...

    // 改为静态方法，传入配置
    public static Ina226Data Parse(byte[] resp);  // 不变

    // 换算方法改为实例方法，传入配置
    public double GetBusVoltage(Ina226Config cfg)
        => RawBusVoltage * cfg.VoltageLSB / 1000.0;

    public double GetCurrent(Ina226Config cfg)
        => RawCurrent * cfg.CurrentLSB;

    public double GetPower(Ina226Config cfg)
        => RawPower * cfg.PowerMultiplier * cfg.CurrentLSB;
}
```

## 7. Form1.cs 改造要点

1. 构造函数中：`_config = AppConfig.Load(configPath)`
2. 串口连接时：用 `_config.Serial` 的参数创建 SerialPort
3. 图表初始化时：用 `_config.Chart` 设置间隔和点数
4. INA226 读取时：传入 `_config.Ina226` 给换算方法
5. 调试日志：用 `_config.Debug` 控制启用和行数限制
6. 窗口关闭时：保存窗口位置到配置
7. ComboBox 初始化时：用配置的 options 填充

## 8. 实现顺序

| 步骤 | 内容 |
|------|------|
| 1 | 新建 AppConfig.cs（模型 + Load/Save/CreateDefault） |
| 2 | 改造 Ina226Data.cs（换算接收配置） |
| 3 | 改造 Form1.cs（加载配置、应用到各处、关闭时保存） |
| 4 | 编译验证 |
