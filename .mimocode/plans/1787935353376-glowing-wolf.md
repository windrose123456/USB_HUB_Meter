# Bootloader 固件接收和 Flash 写入实现

## 目标
在 bootloader.c 中实现完整的 IAP 协议：INFO/ERASE/WRITE/REBOOT

## 协议命令

| CMD | 值 | 发送格式 | 响应 |
|-----|-----|----------|------|
| BL_INFO | 0x05 | 无参数 | [ACK][芯片信息] |
| BL_ERASE | 0x01 | [AH][AL] | [ACK] |
| BL_WRITE | 0x02 | [AH][AL][LEN][DATA...] | [ACK] |
| BL_REBOOT | 0x04 | 无参数 | [ACK] 然后复位 |

## 修改文件
- `bootloader/src/bootloader.c`

## 实现内容

### 1. 主循环命令处理
```c
while (1) {
    cmd = uart_recv_tout(30000);
    if (cmd == 0) jump_app();

    switch (cmd) {
    case BL_INFO:
        uart_send(BL_ACK);
        uart_send('S'); uart_send('T'); uart_send('C');
        uart_send('8'); uart_send('G');
        uart_send(0x08);  // 8KB
        break;

    case BL_ERASE:
        addr = uart_recv_tout(2000) << 8;
        addr |= uart_recv_tout(2000);
        if (addr < APP_SIZE)
            iap_erase_page(addr);
        uart_send(BL_ACK);
        break;

    case BL_WRITE:
        addr = uart_recv_tout(2000) << 8;
        addr |= uart_recv_tout(2000);
        len = uart_recv_tout(2000);
        if (len > 32) len = 32;
        for (i = 0; i < len; i++)
            buf[i] = uart_recv_tout(2000);
        for (i = 0; i < len; i++)
            iap_write(addr + i, buf[i]);
        uart_send(BL_ACK);
        break;

    case BL_REBOOT:
        uart_send(BL_ACK);
        delay_ms(20);
        set_flag(0x00);  // 清除 IAP 标志
        delay_ms(20);
        jump_app();
        break;

    default:
        uart_send(BL_NAK);
        break;
    }
}
```

### 2. IAP 操作函数（已有）
- iap_read() - 读取 Flash
- iap_write() - 写入 Flash
- iap_erase_page() - 擦除页
- set_flag() - 设置标志
- jump_app() - 跳转到应用
