# INA226 I2C Driver Implementation

## 1. Hardware I2C 支持

STC8G1K08A **有硬件 I2C**，寄存器定义在 `STC8H.h:307-315`：
```
I2CCFG   (0xFE80) - 配置寄存器 (使能、速率)
I2CMSCR  (0xFE81) - 主机控制
I2CMSST  (0xFE82) - 主机状态
I2CTXD   (0xFE86) - 发送数据
I2CRXD   (0xFE87) - 接收数据
```

## 2. 400kHz 可行性

| 参数 | 值 |
|------|-----|
| SYSCLK | 11.0592 MHz |
| INA226 I2C 最大频率 | 400 kHz (Fast-Mode) |
| STC8G 硬件 I2C 最大 | 400 kHz (FOSC/30 ≈ 368kHz @ 11.0592M) |

**结论：可以跑 400kHz**。I2CCFG.MSSL=1 设为主机模式，MSpeed[1:0] 选择速率：
- 00: FOSC/24 ≈ 460kHz → 略超 400k，用这个最接近
- 01: FOSC/72 ≈ 154kHz (保守)
- 10/11: 更慢

建议先用 FOSC/24 (≈460kHz)，INA226 spec 允许 400kHz Fast-Mode，实测裕度够用。

## 3. 定时器分配

| Timer | 用途 | 能否释放 |
|-------|------|---------|
| Timer0 | UART 帧超时 (中断) | ✗ 核心功能 |
| Timer1 | UART1 波特率发生器 | ✗ 核心功能 |
| Timer2 | 空闲 | ✓ 可用 |
| Timer3 | 空闲 | ✓ 可用 |
| Timer4 | 空闲 | ✓ 可用 |

**方案：使用硬件 I2C + delay_ms，不占用定时器。**

硬件 I2C 自带时钟生成和起始/停止信号，不需要定时器。读写寄存器只需轮询状态位 + delay_ms 做必要的时序等待。

`delay_ms` (STC8G_H_Delay.c) 是纯循环延时，不依赖定时器，可以安全用于 I2C 时序。

## 4. I2C Pin 映射

用户指定：**P3.2 = SCL, P3.3 = SDA**

STC8G1K08A P_SW2[3:2] 控制 I2C 引脚映射：
- 00: SCL=P3.2, SDA=P3.3 ← 默认值，与用户一致

UART 使用 P3.0/P3.1，不冲突。

## 5. GPIO_config 新增

```c
void I2C_config(void)
{
    // I2C 引脚: P3.2(SCL) P3.3(SDA) 设为准双向上拉
    P3M1 &= ~0x0C;  // P3.2 P3.0 = 准双向
    P3M0 &= ~0x0C;

    // 使能 I2C 扩展寄存器访问
    P_SW2 |= 0x80;

    // I2C 主机模式, 速率 FOSC/24 ≈ 460kHz
    I2CCFG = 0xE0;  // ENI2C=1, MSSL=1, MSpeed=00 (FOSC/24)
}
```

## 6. INA226 驱动函数 (INA226.c)

```c
#include "INA226.h"
#include "STC8G_H_Delay.h"

// 等待 I2C 空闲
static void i2c_wait_idle(void) {
    while (!(I2CMSST & 0x40));  // 等待 SI=0
}

// I2C 起始
static void i2c_start(void) {
    I2CMSCR = 0x01;  // START
    while (!(I2CMSST & 0x40));
}

// I2C 停止
static void i2c_stop(void) {
    I2CMSCR = 0x06;  // STOP
    while (!(I2CMSST & 0x40));
}

// I2C 发送一字节 + ACK
static void i2c_write_byte(u8 dat) {
    I2CTXD = dat;
    I2CMSCR = 0x02;  // SEND
    while (!(I2CMSST & 0x40));
}

// I2C 读取一字节 + ACK/NAK
static u8 i2c_read_byte(u8 ack) {
    I2CMSCR = ack ? 0x04 : 0x05;  // READ_ACK / READ_NAK
    while (!(I2CMSST & 0x40));
    return I2CRXD;
}

// INA226 写寄存器 (2字节数据)
void INA226_WriteReg(u8 reg, u16 val) {
    i2c_start();
    i2c_write_byte(INA_ADDR << 1);  // 地址 + W
    i2c_write_byte(reg);
    i2c_write_byte((u8)(val >> 8));
    i2c_write_byte((u8)(val & 0xFF));
    i2c_stop();
}

// INA226 读寄存器 (2字节)
u16 INA226_ReadReg(u8 reg) {
    u16 val;
    i2c_start();
    i2c_write_byte(INA_ADDR << 1);  // 地址 + W
    i2c_write_byte(reg);
    i2c_start();  // 重复起始
    i2c_write_byte((INA_ADDR << 1) | 1);  // 地址 + R
    val = (u16)i2c_read_byte(1) << 8;  // 读高字节 + ACK
    val |= i2c_read_byte(0);            // 读低字节 + NAK
    i2c_stop();
    return val;
}

// INA226 初始化
void INA226_Init(void) {
    u16 id = INA226_ReadReg(REG_MFR);
    if (id != 0x5449) return;  // 未检测到芯片

    INA226_WriteReg(REG_CFG, 0x0247);  // 配置: 1次平均, 1.1ms转换
    INA226_WriteReg(REG_CAL, 0x1400);  // 校准: Rshunt=10mΩ, MaxI=3.2A
}

// 读取电压/电流/功率 (10字节)
void INA226_ReadAll(u8 *buf) {
    u16 raw;
    raw = INA226_ReadReg(REG_BV);   buf[0]=raw>>8; buf[1]=raw;
    raw = INA226_ReadReg(REG_SV);   buf[2]=raw>>8; buf[3]=raw;
    raw = INA226_ReadReg(REG_CUR);  buf[4]=raw>>8; buf[5]=raw;
    raw = INA226_ReadReg(REG_PWR);  buf[6]=raw>>8; buf[7]=raw;
    raw = INA226_ReadReg(REG_MFR);  buf[8]=raw>>8; buf[9]=raw;
}
```

```c
void I2C_config(void);  // 声明

void main(void) {
    EAXSFR();
    GPIO_config();
    I2C_config();       // 新增: 初始化硬件 I2C
    TIMER_Config();
    UART_config();
    EA = 1;
    delay_ms(100);
    INA226_Init();      // 新增: 初始化 INA226
    // ... main loop
}
```
