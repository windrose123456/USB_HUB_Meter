# 重构 RX/TX 调试日志与原始数据框

## 目标
将当前的两个框（调试日志 + Raw RX）合并为一个串口终端，类似串口助手，支持：
- 设备主动上报数据实时显示
- 固件更新的 TX/RX 统一显示
- 用颜色区分 TX/RX
- 保留命令名（如 SET_LED、GET_DATA）

---

### 2. 新增后台监听线程 (Form1.cs)

```csharp
// 新增字段
Thread? _serialMonitorThread;
CancellationTokenSource? _monitorCts;

// 启动监听
void StartSerialMonitor()
{
    _monitorCts = new CancellationTokenSource();
    _serialMonitorThread = new Thread(SerialMonitorLoop)
    {
        IsBackground = true,
        Name = "SerialMonitor"
    };
    _serialMonitorThread.Start(_monitorCts.Token);
}

// 监听循环
void SerialMonitorLoop(object? state)
{
    var ct = (CancellationToken)state!;
    while (!ct.IsCancellationRequested && _connected && _port?.IsOpen == true)
    {
        try
        {
            if (_port.BytesToRead > 0)
            {
                byte b = (byte)_port.ReadByte();
                // 收集完整帧或超时后显示
                CollectAndDisplay(b);
            }
            else
            {
                Thread.Sleep(1);
            }
        }
        catch { break; }
    }
}

// 停止监听
void StopSerialMonitor()
{
    _monitorCts?.Cancel();
    _serialMonitorThread?.Join(500);
}
```

### 3. 统一显示方法 (Form1.cs)

```csharp
enum RxTxType { Tx, Rx, Raw }

void AppendTerminal(RxTxType type, byte[] data, string? cmdName = null)
{
    string timestamp = $"[{DateTime.Now:HH:mm:ss.fff}]";
    string hex = BitConverter.ToString(data).Replace("-", " ");
    string label = type switch
    {
        RxTxType.Tx => "TX",
        RxTxType.Rx => "RX",
        _ => "RX"  // 主动上报也算 RX
    };

    // 构建显示行
    string line = cmdName != null
        ? $"{timestamp} {label}  {cmdName}  {hex}"
        : $"{timestamp} {label}  {hex}";

    // 颜色
    Color color = type == RxTxType.Tx
        ? Color.FromArgb(46, 204, 113)   // 绿色
        : Color.FromArgb(100, 149, 237); // 蓝色

    // 写入日志文件
    _logFile.WriteLine($"[{label}] {line}");

    // 更新UI (线程安全)
    if (InvokeRequired)
    {
        BeginInvoke(() => AppendTerminal(type, data, cmdName));
        return;
    }

    rtbDebug.SelectionStart = rtbDebug.TextLength;
    rtbDebug.SelectionLength = 0;
    rtbDebug.SelectionColor = color;
    rtbDebug.AppendText(line + "\n");
    rtbDebug.SelectionColor = Theme.TextDim;
    rtbDebug.ScrollToCaret();

    // 限制行数
    if (rtbDebug.Lines.Length > _config.Debug.MaxLines)
    {
        rtbDebug.SelectionStart = 0;
        rtbDebug.SelectionLength = rtbDebug.GetFirstCharIndexFromLine(100);
        rtbDebug.SelectedText = "";
    }
}
```

### 4. 修改 SendCmd (Form1.cs)

**之前**:
```csharp
byte[]? SendCmd(byte cmd, byte[]? data, int timeoutMs = 1000)
{
    byte[] pkt = _proto.BuildPacket(cmd, data);
    LogTx(pkt);                              // 旧: 单独的 LogTx
    _port.Write(pkt, 0, pkt.Length);
    var allBytes = ReadAllBytes(timeoutMs);  // 旧: 手动读取
    AppendRaw(...);                          // 旧: 写入 rtbRaw
    var resp = TryParseFrame(allBytes);
    if (_lastRawFrame != null)
        LogRx(_lastRawFrame, pkt[3]);        // 旧: 单独的 LogRx
    return resp;
}
```

**之后**:
```csharp
byte[]? SendCmd(byte cmd, byte[]? data, int timeoutMs = 1000)
{
    byte[] pkt = _proto.BuildPacket(cmd, data);
    string cmdName = _proto.GetCmdName(pkt[3]);
    AppendTerminal(RxTxType.Tx, pkt, cmdName);  // 新: 统一显示

    _port.DiscardInBuffer();
    _port.Write(pkt, 0, pkt.Length);

    // 等待响应 (后台线程会捕获数据到缓冲区)
    var resp = WaitForResponse(timeoutMs);

    if (resp != null && _lastRawFrame != null)
        AppendTerminal(RxTxType.Rx, _lastRawFrame, cmdName + "(Resp)");

    return resp;
}
```

### 5. 后台监听的响应捕获

```csharp
// 响应缓冲区
byte[] _responseBuffer = new byte[256];
int _responseCount = 0;
ManualResetEventSlim _responseReceived = new(false);

// 监听线程中调用
void OnByteReceived(byte b)
{
    _responseBuffer[_responseCount++] = b;
    // 尝试解析帧
    if (_responseCount >= 5)
    {
        int dataLen = _responseBuffer[2];
        if (_responseCount >= 5 + dataLen)
        {
            var frame = _responseBuffer[.._responseCount];
            var payload = _proto.ValidatePacket(frame, _responseCount);
            if (payload != null)
            {
                _lastRawFrame = frame;
                _responseReceived.Set();
                // 非命令响应 → 主动上报
                if (!_waitingForCommandResponse)
                    AppendTerminal(RxTxType.Rx, frame);
            }
        }
    }
}

// SendCmd 中等待
byte[]? WaitForResponse(int timeoutMs)
{
    _responseReceived.Reset();
    _responseCount = 0;
    _waitingForCommandResponse = true;

    if (_responseReceived.Wait(timeoutMs))
    {
        _waitingForCommandResponse = false;
        return _proto.ValidatePacket(_lastRawFrame!, _lastRawFrame!.Length);
    }

    _waitingForCommandResponse = false;
    return null;
}
```

### 6. 固件更新适配 (FirmwareUpdater.cs)

**修改**: 将 `LogRaw` 事件改为调用统一的终端显示

```csharp
// 之前
void LogRaw(string msg) => RawLog?.Invoke($"[{DateTime.Now:HH:mm:ss.fff}] {msg}");

// 之后 - 在 Form1 中订阅时转换
_fwUpdater.RawLog += msg =>
{
    // 解析 msg 中的 TX/RX 标记，调用 AppendTerminal
    var type = msg.StartsWith("TX") ? RxTxType.Tx : RxTxType.Rx;
    var bytes = ParseHex(msg);
    AppendTerminal(type, bytes, "FW");
};
```
